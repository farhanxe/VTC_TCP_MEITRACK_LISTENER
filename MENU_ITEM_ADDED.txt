  WHAT THE MENU ITEM DOES
═══════════════════════════════════════════════════════════════════════════

When you click "6066 — VT200L" or press F5:

1. Creates new frm6066 instance
2. Sets it as MDI child (docks inside main window)
3. Shows the form
4. Logs "frm6066" to audit log

The form will show:
  ✅ VT200L Server on port 6066
  ✅ Real-time connection statistics
  ✅ Active connections list
  ✅ Live packet log
  ✅ System metrics (CPU, Memory, Rate)

  TROUBLESHOOTING

❌ Problem: Menu item doesn't appear after building
────────────────────────────────────────────────────────────────────────────
Solution: Clean and rebuild
  1. Visual Studio → Build → Clean Solution
  2. Build → Rebuild Solution


❌ Problem: Form doesn't open when clicking menu
────────────────────────────────────────────────────────────────────────────
Solution: Check build errors
  1. View → Error List
  2. Fix any compilation errors
  3. Rebuild


❌ Problem: Error when opening form
────────────────────────────────────────────────────────────────────────────
Check:
  [ ] frm6066.cs exists in WInForm folder
  [ ] frm6066.Designer.cs exists
  [ ] frm6066.resx exists
  [ ] All three files included in project
