Index | Value                    | Description

5     | 90.620880                | Longitude

7     | A                        | GPS validity (A=valid, V=invalid)
8     | 10                       | Satellites
9     | 23                       | GSM signal strength

14    | 766                      | Mileage

16    | 470|1|E54D|026F9548      | Cell tower info (MCC|MNC|LAC|CellID)
17    | 0000                     | IO Port status ← CURRENT CHECK
18    | 0000|0000|0000|0184|09A5 | Analog values (AD1|AD2|...)
19    | 00000001                 | Status flags
20    | 1                        | Battery level
21-25 | (empty fields)           | Reserved/optional
26    | *04                      | Checksum

## IO Port Field (Index 17): 0000

Binary: 0000 0000 0000 0000

Bit breakdown:
- Bit 0 (LSB): 0 - ACC/Ignition status
- Bit 1:     0 - Door status
- Bit 2:     0 - Custom input 1
- Bit 3:     0 - Custom input 2
- etc.

## Current Code Logic:
```csharp
DeriveEngineStatus(eventCode="35", ioPortHex="0000")
  if (eventCode == "1") return "1";  // Ignition ON event
  if (eventCode == "9") return "0";  // Ignition OFF event
  return ((0x0000 & 0x01) != 0) ? "1" : "0";  // Check bit 0
  // Result: 0 (OFF)
```

## PROBLEM IDENTIFIED:

All packets show:
- Field 17 (IO Port) = 0000
- Event code = 35 (interval report, not ignition event)
- Current code: Check bit 0 of 0x0000 → Result: "0" (OFF)

But the device IS active (moving at speeds 1-10 km/h, multiple satellites).

## POSSIBLE ISSUES:

1. **Bit 0 is NOT the ACC bit for this device model**
   - May need to check a different bit (e.g., bit 2, bit 3)
   
2. **IO Port field is not populated**
   - Device may not have ACC connected to IO port
   - Need to check Status flags (field 19) instead

3. **ACC status is in Status flags field (index 19)**
   - Value: 00000001 (hex) = 0000 0000 0000 0000 0000 0000 0000 0001 (binary)
   - May need to check this field instead
